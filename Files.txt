LevelSet:
	LevelSetExtensionFilter.h			used in SegLevelSetDriver as segmentation filter
										A generic extension of a filter (intended to be a 
										FiniteDifferenceImageFilter) that let's user control
										it in a VCR (play-stop-step-rewind) fashion.
										superclass is segmentation filter, eg. 
										GeodesicActiveContourLevelSetImageFilter.
	LevelSetStopAndGoFilter.h/txx		not used, commented #include in SegLevelSetDriver.h
	SegAdvectionFieldImageFilter.h/txx	used in SegLevelSetFunction
	SegLevelSetDriver.h/txx				top level set class. Create, run levelset seg filter
	SegLevelSetFunction.h/txx			difference func, used by PARALLEL_SPARSE_FIELD_SOLVER,
										DENSE_SOLVER but not currently GEO_ACT_CONT or
										GEO_ACT_CONT_SHAPE. Added to those 02-aug-17.
	SegParameters.h/cc					Holds segmentation params
	SignedDistanceFilter.h/txx			not used. Computes an inside/outside signed distance
										image given a binary image of the 'inside'.
